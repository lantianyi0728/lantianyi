### 环境坑：这台机器上没有可用的回收站

- 想按"先入回收站"的稳妥做法删文件，两条路都被安全策略堵死：
  - `Add-Type -AssemblyName Microsoft.VisualBasic` → **被拦**（"Add-Type compiles and loads .NET code at runtime"）。
  - `New-Object -ComObject Shell.Application` → **被拦**（"COM object instantiation can run arbitrary code"）。
- 直接调 `[Microsoft.VisualBasic.FileIO.FileSystem]::DeleteFile(..., 'SendToRecycleBin')` 不报编译错，但抛"无法找到指定文件"——**实际上文件已经没了**（沙箱的 safe-delete 机制接管了，和之前 `Remove-Item` 报错但实际删掉是同一个现象）。
- 结论：这个环境里**删除操作不要相信返回值/异常**，删完必须用 `Test-Path` 复核。
- 可用且可靠的删法：`[System.IO.File]::Delete($path)`；目录用 `[System.IO.Directory]::Delete($path, $true)`。
